# Resourceful Bees JSON Reference

This is a starter documentation set generated from the Resourceful Bees
JSON templates and Draft 2020-12 schemas produced during codec analysis.

The documentation is organized for GitBook-style Markdown navigation,
but the pages are intentionally plain Markdown so they can also be
adapted to MkDocs, Docusaurus, VitePress, or another static-site
generator.

## How to use this bundle

Start with `SUMMARY.md` for navigation. Machine-readable templates and
schemas are copied into `reference/`. Human-readable pages combine
schema-derived field information with known runtime behavior that JSON
Schema cannot express.

## Accuracy convention

The documentation distinguishes between structures resolved from codecs
and intentionally permissive areas. Deep Minecraft/NeoForge structures
that were not fully reverse-engineered are not presented as stricter
than the available source supports.
